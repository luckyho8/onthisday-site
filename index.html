작업판 사이트의 "제작 노트" 탭에 그대로 실린다 (scripts/build_site.py). 틈틈이 읽고 더 찾아볼 거리를 모은 문서다. 마지막 갱신: 2026-11-12

1. 지금 영상이 만들어지는 순서

단계 사용자가 하는 말 Claude가 하는 일 사용자가 하는 일
A. 주제 "주제" 위키 두 곳(영어 On This Day, 한국어 "M월 D일")을 모으고, 이미 쓴 주제를 빼고, 후보 표와 묶음 2~3안을 낸다 묶음 고르기
B. 계획 "1안" 사실 확인 → 원고 → 컨셉 고르기 → 스토리보드 → Fable 교차 검토(사실 + 모션 계획 두 갈래) 계획 승인
C. 제작 "이대로 제작" script.json 작성 → check → 스냅샷으로 모양 확인 → 렌더 → 측정(멈춤·음량) → Fable 렌더 검수 → 고쳐 다시 렌더 영상 보고 OK / 번호로 고칠 곳
D. 게시 "올렸어" + 링크 게시 기록, 다음 날 수치 기록 폰으로 릴스·쇼츠 업로드
  • 사실 확인이 가장 중요하다. 한 출처에만 있거나 출처끼리 다르면 쓰지 않는다 (예: '마이 토킹 톰' 출시일이 출처마다 11·12·13일 → 뺐다).
  • 검토는 다른 모델(Fable)이 독립적으로 한다. 작성자의 근거를 보지 않고 처음부터 다시 확인하게 해서 같은 실수를 피한다.
  • 렌더 뒤에는 0.5초 간격 번호 붙은 프레임 모음을 만든다. 사용자는 "#17 빼"처럼 번호로 짚으면 된다.

2. 컨셉 (곡 + 박자 틀 + 색 + 움직임 + 효과음)

1호 콜라주 × 힙합 2호 신스웨이브 × 레트로 네온
첫 영상 11-12 보이저 (18초, 주제 1개) 11-13 LG·판타지아·보물섬 (48.5초, 주제 3개)
곡 힙합 631168, 95 BPM 신스웨이브 578487, 110 BPM
그림 찢은 종이 + 옛 실사 사진(퍼블릭 도메인) 전부 코드로 그린 네온 선
시그니처 숫자 카드가 굴러가는 연도 다이얼 LED 점 숫자 다이얼, TV 채널 넘김
어울리는 주제 옛 사진이 많은 우주·발명·옛 인물 사진을 못 쓰는 주제(살아 있는 인물, 상표), 신나는 주제
문서 docs/컨셉_콜라주힙합.md docs/컨셉_신스웨이브네온.md
  • 왜 음악부터 정하나: 모든 움직임이 박(beat)에 맞춰 놓인다. 곡이 정해져야 1박이 몇 초인지 정해지고, 그래야 장면 길이·글 머무는 시간·효과음 자리가 정해진다. 그래서 "주제 분위기 → 컨셉(곡이 들어 있음) → 박자 틀 → 장면" 순서다.
  • 같은 컨셉 안에서는 같은 곡을 계속 쓴다. 박자 틀을 재사용할 수 있고, 계정의 소리가 된다.

조사만 한 도구: Earshot

  • Leon Lin이 만든 오픈소스(MIT)다. AI 코딩 에이전트에게 귀를 달아 주는 도구로, GPU 없이 PC에서 돈다.
  • 우리에게 쓸모 있을 기능
  • 효과음 252개를 코드로 합성한다 (sfx, kit). 녹음 파일이 아니라서 우리 sfx.py와 같은 방식이다.

  • critique: 런칭 영상 7편 기준으로 점수와 고칠 곳을 준다.
  • measure: 음량과 박자를 잰다.
  • 한계: 취향(듣기 좋은가)은 판단하지 못한다. 처음 쓸 때 모델 약 1.1GB를 받는다. 검증은 한 사람이 작게 한 것뿐이다.
  • 할 일: 지금 효과음과 Earshot 효과음을 A/B로 들어 보고 더 나으면 쓴다 (아직 설치 안 함).

4. 유튜브·인스타 영상을 분석하는 법

예전에는 링크만 주면 분석이 안 됐다. 웹 페이지 읽기 도구는 영상의 글자 설명만 보고, 영상 자체를 보거나 듣지 못하기 때문이다. 지금은 아래 순서로 직접 받아서 본다 (스킬 hookbank, 2026-11-11부터).

  1. 받기: yt-dlp로 영상을 이 PC에 받는다 (research/, git·드라이브에는 올리지 않음).
  2. 받아쓰기: Whisper로 말과 자막을 글로 만든다.
  3. 보기: ffmpeg로 0.5초·1초 간격 장면 모음과 앞 3초 클립을 만든다. Claude는 이 그림을 직접 본다.
  4. 재기: motion_measure.py로 멈춤%, 큰 변화 간격, 움직임 양, 대표 색을 잰다. 우리 영상과 같은 잣대로 표에 나란히 놓는다.
  5. 정리: 몇 초에 무엇이 일어나는지, 왜 붙잡히는지를 문서로 남긴다.
  • 사례: "디자인하는AI" 영상(youtu.be/H7vcFRCs13w) 분석 → docs/2026-11-12_참고영상_분석_디자인하는AI.md. 여기서 "루즈함의 정체는 멈춘 시간이 아니라 큰 변화 사이 간격"이라는 걸 찾았다.
  • 받은 남의 영상은 분석에만 쓰고, 재가공해서 올리지 않는다.

6. 더 다듬을 것 (제작 과정)

  1. 한 명령으로 제작: 지금은 build → check → snapshot → render → 측정 → 프레임 모음을 따로 돌린다. make 한 번으로 묶고, 결과 표를 자동으로 만든다.
  2. 렌더 전 미리보기(애니매틱): 스냅샷 몇 장으로 장면 흐름을 먼저 보여 주면 렌더(몇 분) 전에 방향을 고칠 수 있다.
  3. 부품 창고 키우기: 컨셉 2호의 그림 부품(전광판·스크린·지도·금고)처럼 주제 종류별 부품을 늘린다. 부품이 많을수록 새 영상이 빨라진다.
  4. 컨셉 3호: 차분하거나 진지한 과학 주제용 (느린 일렉트로닉 또는 로파이). 음원이 더 필요하다.
  5. 수치로 배우기: 게시 다음 날 평균 시청 시간·끝까지 본 비율·저장·공유를 기록한다. 한 번에 한 가지만 바꿔(훅 형식, 길이 30초 vs 48초) 비교한다.
  6. 스킬로 묶기: 흐름이 안정되면 A~D를 하나의 스킬로 만든다 ("주제" → … → "렌더" → 캡션·드라이브까지).
  7. 효과음 A/B: 지금 합성음 vs Earshot.
  8. 작업판 사이트: 게시 탭(캡션 복사), 제작 노트, 용어집. 나중에 영상 미리보기도 넣는다.

모션그래픽 용어집 (프롬프트 쓰는 법)

영상을 말로 주문할 때 쓰는 단어 모음. 각 항목은 영어 용어 → 뜻 → 이렇게 말하면 됨 순서. 프롬프트에는 영어 용어를 그대로 섞어 써도 된다 (Claude·HyperFrames·Remotion 모두 영어 용어를 잘 알아듣는다).

0. 프롬프트 뼈대

[길이·비율] 25초, 9:16 세로 릴스
[주제·한 줄 이야기] 마리 퀴리 탄생일, 노벨상을 두 번 받은 첫 사람
[스타일] kinetic typography, bold condensed type + italic serif accent, flat colors
[색] cream / ink black / tomato / lime 4색, 강조 때 배경색 hard cut
[리듬] 120 BPM, cut on the downbeat, 숫자는 odometer count-up
[전환] pixel dissolve, whip pan, glitch 한 번만
[소리] 8비트 배경음 + whoosh, pop, tick 효과음, ducking
[계정 요소] 맨 위 HUD 라벨, 끝에 end card 1초
[금지] 일러스트·사람 얼굴 없음, 글자는 화면 위아래 UI 영역 밖

→ 이 순서로 한 줄씩만 채워도 결과가 크게 달라진다.

1. 스타일 (전체 느낌)

용어 뜻 이렇게 말하면 됨
Kinetic typography (키네틱 타이포) 글자 자체가 움직이며 이야기하는 영상 "kinetic typography 위주로, 그림 없이 글자로만"
Flat design (플랫) 그림자·질감 없는 단색 면 "flat colors, no gradients"
Swiss / International style (스위스 스타일) 격자에 맞춘 깔끔한 배치, 굵은 산세리프, 여백 많음 "Swiss grid layout, lots of whitespace"
Brutalist / Neo-brutalism (브루탈리즘) 일부러 투박하게: 두꺼운 검은 테두리, 원색, 딱딱한 그림자 "neo-brutalist: thick black outlines, hard drop shadows"
Risograph (리소그래프) 리소 인쇄처럼 색이 살짝 어긋나고 거친 점 질감 "risograph print look, grainy, slight color misregistration"
Halftone (하프톤) 신문 사진처럼 크고 작은 점으로 명암 "halftone dot texture on shapes"
Duotone (듀오톤) 두 가지 색만으로 이미지 표현 "duotone tomato and ink"
Y2K 2000년대 초 느낌: 크롬, 반짝이, 버블 글씨 "Y2K chrome bubble type"
Retro pixel / 8-bit (픽셀) 오래된 게임 화면처럼 네모 점 "8-bit pixel style, chunky pixels"
Doodle / Hand-drawn (낙서·손그림) 펜으로 그린 듯 삐뚤빼뚤한 선 "hand-drawn doodle lines, wobbly strokes"
Line art (선화) 색 없이 선만 "single-weight line art"
Paper cut-out (페이퍼 컷아웃) 색종이를 오려 붙인 느낌, 살짝 그림자 "paper cut-out collage with soft shadows"
Collage (콜라주) 사진·글자·도형을 오려 붙여 섞음 "scrapbook collage"
Claymation (클레이) 찰흙 인형 느낌 "clay-like 3D characters"
Isometric (아이소메트릭) 비스듬히 위에서 본 입체 (게임 지도 같은) "isometric 3D blocks"
Glassmorphism (글래스) 반투명 유리판 + 뒤 흐림 "frosted glass cards"
Editorial (에디토리얼) 잡지 표지처럼 큰 제목 + 세리프 "editorial magazine layout"
Brain rot (브레인롯) 정신없이 빠르고 과장된 요즘 밈 영상 "chaotic brain rot energy" (짧게 강조할 때만)
Showreel (쇼릴) 실력을 보여 주는 하이라이트 모음 "like a motion designer's showreel"

2. 글자 (타이포그래피)

용어 뜻 이렇게 말하면 됨
Sans-serif / Serif 삐침 없는 글꼴(고딕) / 삐침 있는 글꼴(명조) "bold sans for headlines, italic serif for accents"
Condensed (컨덴스드) 폭이 좁고 키 큰 글꼴. 큰 숫자에 잘 맞음 "tall condensed numbers"
Weight (굵기) Thin ~ Black "weight contrast: black vs light"
Kerning / Tracking 글자 사이 간격 (두 글자 / 전체) "tight tracking on headlines"
Accent word 문장 중 색·크기로 튀게 한 단어 "highlight the accent word in lime"
Typewriter (타자기) 한 글자씩 찍힘 + 커서 "typewriter reveal with blinking cursor"
Word-by-word 단어 하나씩 등장 "word-by-word reveal on each beat"
Mask reveal (마스크) 보이지 않는 창이 열리며 글자가 드러남 "mask reveal from bottom"
Slam / Punch-in (슬램) 크게 쾅 박히며 등장 "slam in the key word with a punch zoom"
Stagger (스태거) 여러 글자·요소가 차례로 조금씩 늦게 "stagger letters by 0.03s"
Odometer / Count-up (카운터) 숫자가 굴러가며 올라감 "odometer count-up from 0000 to 1867"
Lower third (로어 서드) 화면 아래쪽 이름표 자막 우리는 인스타 UI 때문에 아래쪽을 비움

3. 움직임 (애니메이션 원리)

용어 뜻 이렇게 말하면 됨
Easing (이징) 속도 변화. 일정하지 않고 빨라졌다 느려짐 "smooth easing, nothing linear"
Ease out / Ease in 빨리 시작해 천천히 멈춤 / 천천히 시작해 빨라짐 등장은 ease out, 퇴장은 ease in
Overshoot / Back 목표보다 살짝 지나쳤다 돌아옴 (통통) "slight overshoot on pops"
Bounce / Elastic 공처럼 튕김 / 고무줄처럼 출렁 "elastic bounce" (과하면 유치)
Squash & stretch 떨어질 때 찌그러지고 늘어남 "squash and stretch on landing"
Anticipation 움직이기 전 반대로 살짝 웅크림 "small anticipation before the jump"
Follow-through / Overlap 멈춘 뒤에도 일부가 조금 더 움직임 "follow-through on secondary elements"
Secondary motion 주인공 말고 주변의 작은 움직임 "subtle secondary motion in background shapes"
Hold (홀드) 움직임을 멈추고 보여 주는 시간 "hold each line at least 1.5s" ← 읽힘의 핵심
Loop 끊김 없이 반복 "seamless loop"
Parallax (패럴랙스) 앞은 빨리, 뒤는 천천히 움직여 깊이감 "parallax layers"
Morph (모프) 한 모양이 다른 모양으로 변함 "morph the circle into the number 2"
Path animation 정해진 길을 따라 움직임 "paper plane follows a curved path"
Particles (파티클) 작은 점·조각들이 흩날림 "confetti particles burst"
Stop motion (스톱모션) 일부러 끊기게 (초당 8~12장) "stop-motion feel, animate on twos"
On twos / ones 2프레임마다 / 매 프레임 그림 바뀜 "on twos" = 손으로 만든 느낌

4. 전환 (장면 넘어가기)

용어 뜻 이렇게 말하면 됨
Hard cut (하드 컷) 그냥 탁 바뀜 "hard cut on the downbeat"
Smash cut 조용하다 갑자기 시끄럽게 확 바뀜 "smash cut to the reveal"
Match cut 앞뒤 장면의 모양을 맞춰 이어 붙임 "match cut: the 0 becomes the sun"
Crossfade / Dissolve 겹치며 서서히 바뀜 (잔잔할 때만)
Wipe (와이프) 선이 지나가며 다음 장면이 덮음 "diagonal wipe"
Iris (아이리스) 원이 커지거나 작아지며 바뀜 "circle iris out"
Pixel dissolve 네모 점들이 흩어지며 바뀜 "pixel dissolve transition"
Whip pan (휩 팬) 카메라를 휙 돌린 듯 흐리게 밀림 "whip pan with motion blur"
Glitch (글리치) 화면이 지직 깨지고 색이 어긋남 "RGB split glitch, 4 frames"
Push / Slide 다음 화면이 밀고 들어옴 "push transition upward"
Zoom through 글자·구멍 속으로 들어가며 다음 장면 "zoom through the O into the next scene"
Color flash 한 프레임 단색이 번쩍 "1-frame white flash"

5. 카메라 (가상 카메라)

용어 뜻 이렇게 말하면 됨
Push in / Pull out 앞으로 다가감 / 뒤로 물러남 "slow push in during the hold"
Pan / Tilt 좌우로 돌림 / 위아래로 돌림 "pan left to reveal the timeline"
Dolly / Truck 카메라가 앞뒤로 / 옆으로 이동 "dolly in"
Punch zoom 순간 확대 (박자에) "punch zoom on the beat"
Camera shake 흔들림 "small shake on impact"
Rack focus 초점이 앞→뒤로 옮겨감 "rack focus from text to background"
Depth of field 배경 흐림 "shallow depth of field"
Motion blur 빠른 움직임의 잔상 "motion blur on fast moves"

6. 질감·마감

용어 뜻 이렇게 말하면 됨
Grain / Noise 필름 같은 자글자글한 입자 "subtle film grain"
Vignette 가장자리 어둡게 "soft vignette"
Chromatic aberration 가장자리 색 번짐 (RGB 어긋남) "slight chromatic aberration"
Scanlines 옛날 TV 가로줄 "CRT scanlines" (옛날 느낌에 좋음)
Glow / Bloom 밝은 부분이 번지듯 빛남 "lime glow"
Drop shadow / Hard shadow 부드러운 그림자 / 딱 떨어지는 그림자 "hard offset shadow"
Texture overlay 종이·인쇄 질감을 위에 덮음 "paper texture overlay"

7. 화면 구성

용어 뜻 이렇게 말하면 됨
Safe zone (안전 영역) 앱 UI가 가리지 않는 곳 "keep text inside the reels safe zone"
HUD 화면에 계속 떠 있는 작은 정보 (게임 화면 위 숫자처럼) "persistent HUD with date and progress bar"
Grid (그리드) 보이지 않는 격자에 맞춰 배치 "12-column grid"
Hierarchy (위계) 무엇을 먼저 보게 할지 크기·색 순서 "clear hierarchy: number > label > note"
Negative space (여백) 비워 둔 공간 "generous negative space"
Crop marks 귀퉁이 맞춤 표시 ┌ ┐ "corner crop marks as frame"
End card (엔드 카드) 마지막 계정·로고 화면 "1-second end card with logo"
Bumper / Sting 매번 같은 짧은 로고 장면 (브랜드 각인) "2-second brand sting at the end"
Style frame 렌더 전 대표 장면 몇 장 (시안) "show me 3 style frames first"
Storyboard 장면별 계획표 "storyboard with timing per beat"
Animatic 스토리보드를 시간에 맞춰 대충 움직인 것 "rough animatic before final"

8. 소리

용어 뜻 이렇게 말하면 됨
BPM 1분에 박이 몇 번 (빠르기) "115~125 BPM"
Beat / Bar (마디) / Downbeat 박 / 4박 묶음 / 마디 첫 박 "change scenes on the downbeat"
Drop 음악이 쌓였다 터지는 순간 "reveal on the drop"
Beat sync (비트 싱크) 화면 사건을 박자에 맞춤 "beat-synced cuts"
SFX (효과음) whoosh(휙), pop(퐁), tick(똑), thud/impact(쿵), riser(올라가는 소리), ding(띵), glitch(지직) "add whoosh on every transition"
Riser / Build-up 긴장을 쌓는 올라가는 소리 "1-bar riser before the name"
Stinger 짧은 마무리 소리 "stinger on the end card"
Ducking (덕킹) 효과음·목소리 나올 때 음악을 잠깐 줄임 "duck music -6dB under SFX"
Hit point 소리와 화면이 딱 맞는 지점 "hit points on every number stop"
LUFS 체감 음량 단위 (릴스는 -14 안팎) "master to about -14 LUFS"

9. 이야기 구조

용어 뜻 이렇게 말하면 됨
Hook (훅) 처음 1~2초에 붙잡는 장면 "hook in the first 1.5s, text visible on frame 1"
Setup / Payoff 궁금증 던지기 / 풀어 주기 "setup a question, payoff at 15s"
Reveal 정답 공개 순간 "big reveal on the drop"
Twist 뜻밖의 사실 "save the twist for the last third"
CTA 행동 유도 (저장·공유) "CTA: send to a friend"
Pacing (페이싱) 빠르기 배분 "fast pacing but readable holds"
Rhythm / Contrast 빠름-느림, 큼-작음을 번갈아 "alternate fast and slow beats"

10. 우리 계정에서 써 본 결과 (계속 추가)

  • 2026-11-11 실사 사진 + 구절 자막 13개(15.5초): "글이 너무 빨리 지나감, 툭툭 튐" → hold 시간이 부족했음
  • 2026-11-11 파스텔 일러스트 + 잔잔한 곡(1차 모션): "음악이 너무 진지함" → 곡 선택(BPM·장르)이 분위기의 절반
  • 참고 영상 3개 공통: 120 BPM, 배경색 hard cut, 숫자 count-up, 굵은 글씨 + 기울인 세리프 대비
  • 2026-11-12 보이저 첫 게시본 사람 검수 (자세한 건 docs/컨셉_콜라주힙합.md)
  • "위성이 순간이동해" → continuity (동선 연속성) 깨짐 / pop-in (물체가 갑자기 생김). 말할 때: "no pop-in during transitions, fade in at its start position"
  • "알파 먹은 것처럼 쓰윽 나타나" → fade in (opacity 0→1, 보통 0.3~0.5초)
  • "노란 띠가 내려갔다 다시 올라가" → 의도하지 않은 snap back (값 되돌아감). 의도한다면 retract → extend ("retract fully, then shoot out on the beat")
  • "전환 전에 위로 날아가 버려" → exit animation이 불필요. 말할 때: "hero stays put; only the camera moves out"

11. 제작하면서 쓴 말 (2026-11-12, 계속 추가)

용어 뜻 우리 영상에서
BPM / 박(beat) 1분에 박이 몇 번인지 / 박 하나 신스웨이브 110 BPM → 1박 0.545초. 모든 장면이 박 단위로 놓인다
마디(bar) / 다운비트(downbeat) 4박 묶음 / 마디의 첫 박 주제가 바뀌는 순간을 마디 첫 박에 맞춘다
박자 틀 장면마다 몇 박씩 쓰는지 정한 표 컨셉 2호: 훅 6 / 주제 24~26 / 끝 8
홀드(hold) 글이 화면에 머무는 시간 1.5초 이상
멈춘 프레임(still %) 앞 프레임과 거의 같은 프레임의 비율 25% 이하가 기준. 11-13은 4%
큰 변화 간격 화면이 크게 바뀌는 순간 사이의 시간 1~1.3초(2박)가 사용자에게 맞음. 0.5초면 급하고 1.3초 넘으면 루즈함
슬램(slam) 크게 시작해 쿵 하고 자리 잡는 등장 날짜·숫자 착지
네온 켜짐(flicker on) 간판처럼 두어 번 깜빡이며 켜짐 컨셉 2호 글 등장
와이프(wipe) 띠나 면이 지나가며 장면을 바꾸는 전환 1호: 종이가 위에서 덮음, 2호: 채널 넘김 띠
카메라 다가감 / 물러남 (push in / pull back) 화면 전체를 천천히 키우거나 줄임 장면 끝 다가감, 끝맺음 직전 물러남
둥실(float, bob) 그림이 박마다 몇 px씩 위아래로 떠다님 화면이 멈추지 않게 하는 잔잔한 움직임
동선 연속성(continuity) 물체가 장면 사이에서 자연스럽게 이어짐 "위성이 순간이동해" = continuity가 깨짐
팝인(pop-in) 물체가 아무 예고 없이 갑자기 생김 전환 중에는 새 물체를 띄우지 않는다
페이드 인/아웃(fade) 투명도를 서서히 올리거나 내림 "알파 먹은 것처럼 쓰윽" = fade in
스냅백(snap back) 움직이던 값이 처음 값으로 되돌아감 노란 띠가 짧아졌다 다시 뻗음 (오류였음)
빈 무대(empty stage) 아무것도 담지 않은 요소가 들어왔다 나감 금지. 들어오는 것은 글·그림을 담거나 주인공을 받치거나 다음 장면을 데려온다
안전 영역(safe zone) 플랫폼 글·버튼에 가리지 않는 화면 범위 글자 y 200~1480, 아래쪽 오른쪽 150px 비움
LUFS 사람 귀 기준 평균 음량 쇼츠·릴스는 -14 LUFS 안팎
true peak 소리의 가장 높은 순간 -1 dB 이하 (넘으면 찌그러짐)
Content ID 유튜브가 음악 저작권을 자동으로 찾는 장치 Content ID가 등록된 곡은 대표 곡으로 쓰지 않는다
애니매틱(animatic) 정지 화면 몇 장으로 만든 흐름 미리보기 렌더 전 스냅샷 모음
타임라인(timeline) 모든 움직임을 시각과 함께 적은 표 GSAP 타임라인 하나에 영상 전체를 적는다
